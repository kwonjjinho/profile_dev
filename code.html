PROJECT DOCUMENT / 001 • DISTRIBUTED PAYMENT ENGINE
PERIOD: 2025.04 — 2025.10 • ROLE: LEAD BACKEND ENGINEER

FinFlow — 대용량 트래픽 결제 및 정산 트랜잭션 플랫폼

순간 초당 요청량(TPS) 폭증 시 발생하는 재고 마이너스 및 중복 결제 결함을 원천 차단하고 결제 승인과 정산 프로세스를 디커플링한 분산 백엔드 플랫폼.

warning THE ARCHITECTURAL BOTTLE-NECK

선착순 할인 프로모션 시 1만 회 이상의 동시 결제 요청이 단일 RDBMS 인스턴스로 집중되며 Connection Pool 고갈 및 비관적 락(Pessimistic Lock)으로 인한 심각한 데드락(Deadlock)과 주문 결제 누락 발생.

check_circle ENGINEERED RESOLUTION

Redisson 분산 락(Distributed Lock)을 채택하여 재고 차감 임계 구역의 락 점유 시간을 140ms에서 8ms로 단축. 결제 이후의 장시간 I/O 정산 로직은 Apache Kafka 이벤트로 분리하여 멱등성(Idempotency) 보장.
